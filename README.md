# MPL ID S18 Playoff Predictor

**Aplikasi interaktif untuk mengeksplorasi klasemen dan simulasi skenario hasil pertandingan MPL Indonesia Season 18.**

🔗 **[Buka Live Demo](https://mpl-s18.vercel.app/)** · [Lihat Repository](https://github.com/Fadhail-3596/mpl-s18)

## 📖 Tentang Proyek

MPL ID S18 Playoff Predictor adalah proyek web yang mengeksplorasi hubungan antara hasil pertandingan, perubahan klasemen, dan peluang tim untuk lolos ke babak playoff MPL Indonesia Season 18.

Aplikasi ini memungkinkan pengguna mengeksplorasi skenario hasil pertandingan dan melihat bagaimana hasil yang berbeda dapat memengaruhi posisi tim serta kemungkinan kualifikasi menuju playoff.

Proyek ini dibuat sebagai eksperimen pengembangan aplikasi interaktif yang menggabungkan penyajian data olahraga dan simulasi skenario.

## ✨ Fitur Utama

- **Informasi klasemen** — Menampilkan informasi peringkat tim berdasarkan data yang digunakan aplikasi.
- **Simulasi hasil pertandingan** — Memungkinkan pengguna mengeksplorasi skenario hasil pertandingan.
- **Eksplorasi skenario playoff** — Membantu pengguna memahami bagaimana hasil pertandingan dapat memengaruhi peluang tim untuk lolos.
- **Antarmuka interaktif** — Menyajikan informasi dan hasil simulasi dalam format yang mudah dijelajahi.

## 🛠️ Pendekatan Pengembangan

Proyek ini dikembangkan menggunakan pendekatan **vibe coding dengan bantuan AI Studio Code**. AI digunakan sebagai pendamping dalam proses menerjemahkan ide menjadi aplikasi interaktif, menyusun antarmuka, dan mengembangkan pengalaman eksplorasi skenario pertandingan.

Melalui proyek ini, saya mengeksplorasi bagaimana ide yang berangkat dari ketertarikan terhadap esports dapat dikembangkan menjadi aplikasi web yang memungkinkan pengguna berinteraksi dengan data dan skenario hasil pertandingan.

## 🎯 Tujuan Proyek

Proyek ini dibuat untuk:

- Mengeksplorasi pengembangan aplikasi web interaktif.
- Mempelajari penyajian data dan simulasi skenario pertandingan.
- Bereksperimen dengan pendekatan vibe coding dalam membangun produk digital.
- Mengubah ketertarikan terhadap esports menjadi proyek teknologi yang dapat dicoba langsung.

## ⚠️ Catatan

Hasil simulasi bergantung pada data dan logika yang diterapkan dalam aplikasi. Skenario yang ditampilkan bukan jaminan hasil pertandingan sebenarnya dan tidak selalu merepresentasikan prediksi resmi.
